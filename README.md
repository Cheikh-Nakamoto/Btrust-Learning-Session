## Conseils

1. **Lire le code source** — chaque page learnmeabitcoin montre les calculs en hex. Suivre avec un convertisseur.
2. **Expérimenter avec Rust** — implémenter les concepts au fur et à mesure.
3. **Consulter developer.bitcoin.org** — pour les détails de protocole, formats de données et RPC.
4. **Flashcards** — cartes pour les termes techniques (UTXO, ScriptPubKey, Merkle Root…).
5. **Explorer le réseau** — installer un nœud testnet et observer les blocs/transactions.
